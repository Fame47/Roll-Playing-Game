# BNP's R.P.G. Roll-Playing Game

GitHub Pages build.

## Deploy
Upload the contents of this folder to the root of the GitHub repository.
GitHub Pages should serve `index.html`.

The game is self-contained inside `index.html`. The manifest and icons add
standalone/PWA portrait-orientation support on compatible mobile browsers.

## Optimized GitHub build
Large embedded images/audio were moved into `/assets` so `index.html` stays small. Keep the assets folder beside index.html when deploying.
